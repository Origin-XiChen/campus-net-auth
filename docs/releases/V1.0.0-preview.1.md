首个安装器预览（Velopack，单用户安装，无需管理员）。用于验证安装 / 迁移 / 卸载与预发布更新通道，不建议作为日常使用版本。

## 本版内容

- 安装到 `%LOCALAPPDATA%\CampusNetAuth`，创建桌面与开始菜单快捷方式；
- **首次启动自动迁移**：读取开机自启指向的绿色版目录，把 `config.json / cred.bin / state.json` 导入 `%APPDATA%\CampusNetAuth`，把自启改指安装版，停止旧守护/界面，并把旧目录整体移入回收站（可恢复；失败下次重试）；
- 应用内更新走 Velopack：预发布构建可见预发布 Release；
- 卸载会停止守护、移除自启、删除程序文件与快捷方式；`%APPDATA%` 数据保留。

## 已知限制

- 预发布：GitHub `/releases/latest` 不会推荐给旧版用户；0.6.4 / 0.7.0 的更新检查看不到本版本；
- 未代码签名；安装器暂为一键安装 + 品牌 splash（自绘安装引导器计划在 1.0 正式版前提供）；
- 界面需要 WebView2 运行时（Win10/11 通常已随 Edge 安装）；
- 安装前建议先备份旧绿色目录（迁移会把它移入回收站）。

## 验证

- 自检 19 项全绿；Setup 静默安装后 `--version` = `1.0.0-preview.1`；
- 合成 0.7.0 绿色目录 → 安装版迁移 E2E：导入 3 个数据文件、自启改指、旧目录进回收站；随后卸载并还原本机自启与测试数据。

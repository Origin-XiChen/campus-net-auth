0.7.0 是全量 C# 重写的过渡绿色版：同一个 exe 既是界面也是守护，自包含单文件（无需另装 .NET；界面需要系统 WebView2 运行时，Win10/11 通常已随 Edge 安装）。配置、凭据（DPAPI）、状态、开机自启与 47667 控制协议与 0.6.x 完全兼容，可原地替换旧 exe。

## 升级方式

- 0.6.4 界面「检查更新」→「下载并升级」，或 CLI `CampusNetAuth.exe update`，自动下载校验并替换为 0.7.0；
- 也可手动下载本页 `CampusNetAuth.exe`，退出旧版后覆盖同目录旧 exe（`config.json / cred.bin / state.json` 保留即可）。

## 本版变更

| 类别 | 内容 |
|---|---|
| 重写 | .NET 10 自包含单文件；同一 exe 提供界面 / 守护 / CLI |
| 界面 | 保留原 HTML UI；原生无边框窗口、系统最小化/最大化动画、圆角投影、边缘缩放、标题栏系统菜单、托盘 |
| 通知 | AUMID + 系统气泡通知；守护进程在界面未打开时也能弹（验证码/异常/自愈提醒） |
| 升级 | 绿色版检查更新 + 下载校验（大小 / SHA256 / PE 版本 / ProductName），仍不执行下载文件 |
| 兼容 | 数据目录、DPAPI 凭据、`"<exe>" daemon` 自启、`daemon/status/update/upgrade` 等命令与 0.6.x 一致 |

## 已知限制

- 未代码签名，SmartScreen 可能提示；请只从本仓库 Release 下载；
- 界面依赖 WebView2 运行时（没有 tkinter 回退；Win10/11 一般已安装）；
- 安装器版（1.0.0）开发中，本版为绿色过渡版；安装版上线后会自动导入本版配置并清理旧目录；
- 旧目录里的 `CampusNetAuthUninstall.exe` 仍可用于删除整个绿色目录。

## 2026-11-27 修订

- 修复：界面启动时若守护本来没在运行（例如手动停止后重开界面），不会自动拉起，关闭界面后
  就没有后台守护。现在界面启动会确保守护运行（已启用自启或已配置账号时）；关闭界面不影响
  守护；本次开机内手动停止过则尊重该选择。
- 修复：读取 0.6.4 留下的 `cred.bin`（`DPAPI\x01` 头 + DPAPI blob）失败，导致升级后守护
  起不来。现与 Python 版格式互通，并兼容 0.7.0 早期构建写入的无标记裸 DPAPI。
- 本页 `CampusNetAuth.exe` 已替换为含以上修复的构建（版本号不变，仍为 0.7.0）。

CampusNetAuth **V1.0.1**：1.0.0 的补丁版，汇总发布后的安装与通知修订；本次也用于验证安装版应用内更新（1.0.0 → 1.0.1）。

## 本版变更

- **安装引导器**：修复右侧选项文字溢出、底部按钮被裁切、关闭按钮跑出窗口；高 DPI 缩放一致；
  同版本已安装时显示「重新安装」。
- **门户地址**：保存时拆分 `host:port`，加载时自动修复已有坏配置（不再出现 `:80:80`、门户不可达）。
- **提示窗**：主程序/安装器内的 MessageBox 全部替换为同风格自绘提示窗（ThemedDialog），
  统一圆角 + DWM 阴影。
- **通知**：后台守护进程（无主界面）也能在右下角弹自绘横幅——
  连接成功：蓝色圆圈 + 白勾、圆角卡片、从屏幕外滑入，停留 6s；
  认证失败/验证码/欠费：同风格错误卡，带「打开主程序设置」「取消」，停留 30s，
  并附门户地址、学号（掩码）、运营商。
- 「通知测试」按钮改为走真实通知通道（优先守护进程）；`Notify.System` 后台通知统一横幅。
- 另包含 1.0.0 发布后的修订：卸载只清本安装的自启、守护自愈、`cred.bin` 兼容 0.6.4 等。

## 升级方式

- **已安装 1.0.0**：打开主界面 →「检查更新」→「下载并升级」（Velopack 下载、校验、重启）。
  若卡片仍显示“已是最新”，点一次「检查更新」强制刷新缓存（此前缓存 6 小时）。
- **绿色 0.7.0 / 1.0.0**：界面「检查更新」升级到 1.0.1 绿色版；想换安装版请运行 Installer。
- **新用户**：使用 `CampusNetAuth-Installer.exe`。

## 验证

- 安装版应用内更新 1.0.0 → 1.0.1（本版主要验证项）；
- C# 自检 23 项、CI（Python + C#）全绿；
- 通知横幅/错误卡、安装器布局与阴影均在真机验证。

## 已知限制

- 未代码签名，SmartScreen 可能提示；请只从本仓库 Release 下载。
- 主程序界面需要 WebView2 运行时（Win10/11 通常已随 Edge 安装）。
- 安装引导器约 109 MB（内嵌安装器 + 自包含运行时）。

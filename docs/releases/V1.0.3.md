CampusNetAuth **V1.0.3**：交互反馈与更新公告显示优化；**首个仅发布安装版的版本**。

## 本版变更

### 等待反馈更明确

- **开关**：开机自启、系统代理守卫点击后，滑块先停在中间、轨道变黄；后台返回后再落到目标侧，失败则回原位。轮询刷新不会覆盖中间态。
- **异步按钮**：守护启动/停止/重启、下线、代理关闭/恢复、刷新、保存检测参数、通知测试、抓取诊断、检查更新、打开发布页、卸载启动，点击后立即转圈并禁用。
- 浅色按钮使用深色 spinner；守护启停期间同组按钮一起禁用，完成后按真实状态恢复，不再出现"点了没反应，过一会自己变"。

### 更新公告

- 公告弹窗按安全 Markdown 子集渲染：标题、列表、加粗、行内代码、代码块、引用、分隔线，不再显示 `##`、`**` 等原始符号。
- 加载公告时显示 spinner；下载失败/完成的提示独立展示，不再覆盖公告正文。
- 外链只保留文字，避免把内嵌界面导航离开。

## 分发方式

- **V1.0.3 起 Release 只发布安装版**：安装器、Velopack Setup、nupkg 与更新清单；不再上传绿色单文件。
- 绿色/便携用户请下载 `CampusNetAuth-Installer.exe`。安装会自动导入配置、凭据与开机自启，并把旧目录移入回收站（可恢复）。

## 升级方式

- **已安装 1.0.0 / 1.0.1 / 1.0.2**：主界面 →「检查更新」→「下载并升级」。
- **绿色/便携版**：使用 `CampusNetAuth-Installer.exe` 转为安装版。
- **新用户**：使用 `CampusNetAuth-Installer.exe`。

## 验证

- C# 自检 23 项、Python 离线单测 245 项全绿；界面 JS 语法与 ID 引用校验通过。
- 无头浏览器模拟延迟验证：开关中间态、守护启动按钮转圈与状态落地、公告 Markdown 结构。
- 安装版 1.0.2 → 1.0.3 应用内更新（发布后真机确认）。

## 已知限制

- 未代码签名，SmartScreen 可能提示；请只从本仓库 Release 下载。
- 主程序界面需要 WebView2 运行时（Win10/11 通常随 Edge 安装）。
- 安装引导器约 109 MB（内嵌安装器 + 自包含运行时）。

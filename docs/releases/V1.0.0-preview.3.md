安装版预览 3：首个带**自绘安装引导器**的预览，并汇总预览期的运行修复。

## 安装（推荐）

下载本页 `CampusNetAuth-Installer.exe`（单文件，内嵌安装器）：

- 选择安装位置（默认 `%LOCALAPPDATA%\CampusNetAuth`；已有安装时锁定并显示「更新」）；
- 右侧「选项」：安装完成后启动；
- 安装后的首次启动会自动导入旧版配置、凭据与开机自启，旧目录移入回收站（可恢复）；
- IT / 命令行可直接使用 `CampusNetAuth-win-Setup.exe`；引导器也支持
  `--silent --dir <路径> --no-launch`。

## 本版变更

| 类别 | 内容 |
|---|---|
| 安装器 | WinForms 自绘引导器（不依赖 WebView2）：安装位置、安装/更新按钮、右侧选项、安装中禁止关闭；单文件内嵌 Velopack Setup |
| 守护 | 界面启动确保守护运行（自启开启或已配置账号时），关闭界面不影响守护；本次开机内手动停止则尊重 |
| 凭据 | `cred.bin` 兼容 0.6.4 的 `DPAPI\x01` 头；升级后守护不再报"尚未配置账号密码" |
| 更新 | Velopack 检查结果落盘缓存（成功 6h / 失败 5min），状态轮询只读缓存、过期后台补查；手动检查强制刷新 |
| 卸载 | 卸载钩子只移除指向**本安装目录**的 Run 值，不误删其它绿色部署的开机自启 |
| 构建 | 版本源统一为 csproj `<Version>`，构建可用 `-Version` 覆盖 |

## 已知限制

- 预发布版本；未代码签名，SmartScreen 可能提示；
- 主程序界面需要 WebView2 运行时（Win10/11 通常已随 Edge 安装）；
- 引导器 108 MB（内嵌 62 MB 安装器 + 自包含运行时）；
- 0.7.0 绿色版的更新检查看不到预发布，需要手动下载本页安装器。

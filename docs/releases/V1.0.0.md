CampusNetAuth **V1.0.0 正式版**：全量 C# 实现，提供「安装版」与「绿色单文件」两种形态。

## 安装（推荐）

下载本页 `CampusNetAuth-Installer.exe`（单文件，内嵌安装器）：

- 自绘安装界面：可选安装位置（默认 `%LOCALAPPDATA%\CampusNetAuth`）、右侧「安装完成后启动」；
- 安装到当前用户，无需管理员权限；
- **首次启动自动迁移**：导入旧版配置、凭据与开机自启，停止旧守护/界面，并把旧目录移入回收站（可恢复）。

## 升级路径

- **0.6.4 / 0.7.0 绿色版**：界面「检查更新」→「下载并升级」即可原位升级到 **1.0.0 绿色版**
  （数据、凭据、自启不变）；想切换到安装版，请运行上面的 Installer，数据会自动迁移；
- **1.0 预览安装版（preview.1/.2/.3）**：应用内「检查更新」升级到正式版；
- **新用户**：直接使用 Installer。

## 1.0.0 内容

| 类别 | 内容 |
|---|---|
| 形态 | Velopack 安装版 + 绿色单文件（同一 exe 界面/守护/CLI）；安装引导器单文件内嵌安装器 |
| 迁移 | 自动导入 `config.json / cred.bin / state.json`（不覆盖已有），旧目录移入回收站，失败下次重试 |
| 界面 | 保留原 HTML UI；原生无边框窗口、系统最小化/最大化动画、圆角投影、边缘缩放、系统菜单、托盘 |
| 通知 | AUMID + 系统气泡；守护进程在界面未打开时也能提醒 |
| 守护 | 界面启动确保守护运行；本次开机内手动停止则尊重；只接管同一 exe 的旧守护 |
| 凭据 | `cred.bin` 与 0.6.x 同格式（`DPAPI\x01` 头），兼容 0.7.0 早期裸 DPAPI |
| 更新 | 安装版走 Velopack；检查结果缓存 6h/5min，过期后台补查；绿色版下载校验大小/SHA256/PE 版本/ProductName |
| 卸载 | 停止守护、移除**本安装**的开机自启、删除程序文件与快捷方式；`%APPDATA%` 数据保留 |

## 验证

- C# 离线自检 21 项、Python 245 项全绿；CI 增加 C# 构建与自检；
- 安装 → 迁移（合成旧目录）→ 应用内更新（preview.1 → preview.2）→ 卸载，全链路真机 E2E；
- 安装引导器静默安装/卸载、GUI 冒烟、Run 键归属验证。

## 已知限制

- 未代码签名，SmartScreen 可能提示；请只从本仓库 Release 下载；
- 界面依赖 WebView2 运行时（Win10/11 通常已随 Edge 安装）；
- 安装引导器约 108 MB（内嵌 62 MB 安装器 + 自包含运行时）；绿色单文件约 50 MB。

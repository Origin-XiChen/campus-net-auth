CampusNetAuth **V1.0.2**：界面分区重排，并汇总 1.0.1 资产后续修订；安装版可直接应用内更新。

## 本版变更

### 界面分区重排

- 「连接与账号」拆成两张并排卡片：「校园网账号」集中账号、密码与保存并连接/下线；「网络与运营商」集中运营商、门户地址和选错运营商的提示。
- 「自动化与维护」改为分区网格：后台守护（服务状态、启停、故障提示、最近动态、开机自启）与版本更新各占通栏；系统代理守卫与工具箱并排；彻底卸载通栏；检测参数默认折叠。
- 所有功能、元素 ID、事件与接口保持不变；1180×820 与最小 980×660 下均无横向溢出或卡片裁切。

### 并入 1.0.1 资产后续修订

- 更新卡片缓存按当前版本重算；下载显示百分比、实时速度、已下载/总大小。
- 守护确认在线或登录成功后清理历史错误与失败事件；已认证时不再展示旧登录失败。
- 新版本公告弹窗：展示当前→最新版本与 Release 正文；「稍后」本会话不再打扰；弹窗内显示下载进度。
- 守护确认在线后及在线期间每 6 小时检查版本；主界面未开时右下角提示 20 秒，同版本 12 小时只提示一次。
- 通知测试统一走真实自绘横幅通道（优先守护进程）。

## 分发方式（重要）

- V1.0.2 仍同时提供安装版与绿色单文件。
- **V1.0.2 是最后一个附带绿色包的版本。自下一版起 Release 只发布安装版**；绿色/便携版不再单独发布。
- 绿色/便携用户检查更新时只会看到新版本提示，请打开发布页下载 `CampusNetAuth-Installer.exe`。安装会自动导入配置、凭据与开机自启，并把旧目录移入回收站（可恢复）。

## 升级方式

- **已安装 1.0.0 / 1.0.1**：主界面 →「检查更新」→「下载并升级」。
- **绿色 0.7.0 / 1.0.x**：本次仍可用「检查更新」升级到 1.0.2 绿色版；后续版本请改用安装包。
- **新用户**：使用 `CampusNetAuth-Installer.exe`。

## 验证

- C# 自检 23 项、Python 离线单测 245 项全绿；界面 JS 语法与 ID 引用校验通过。
- 1180×820 与 980×660 两档窗口的 DOM/几何校验：无横向溢出、无卡片内部裁切。
- 安装版 1.0.1 → 1.0.2 应用内更新已实际完成：安装目录与守护均为 1.0.2，远端最新为 1.0.2；`releases.win.json` 与 nupkg 的大小、SHA1/SHA256 一致。

## 已知限制

- 未代码签名，SmartScreen 可能提示；请只从本仓库 Release 下载。
- 主程序界面需要 WebView2 运行时（Win10/11 通常随 Edge 安装）。
- 安装引导器约 109 MB（内嵌安装器 + 自包含运行时）。
